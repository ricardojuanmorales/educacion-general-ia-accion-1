# Archivo del README de EGIA Quest v0.1A

## 1. Declaración de archivo

Este documento preserva el README que describió EGIA Quest durante la fase v0.1A, desde la
activación documental de mayo de 2026 hasta el cierre de la Fase 1 de la migración, el 29 de
agosto de 2026.

Se archiva cumpliendo la doble condición heredada de la Constitución SDD de AI StoryLab:

1. **Existe reemplazo canónico:** el nuevo `README.md` en la raíz del repositorio.
2. **Existe decisión registrada:** `DEC-EGIA-038`.

## 2. Por qué fue sucedido

El README de v0.1A describía con precisión un prototipo que ya no es el estado del proyecto.
Quedó desactualizado en cinco puntos concretos:

- Describía la aplicación como «HTML + JSON + Markdown, sin GitHub Actions», cuando el sucesor
  `apps/egia-quest` usa TypeScript, build y una suite de pruebas.
- Hablaba de retos genéricos, cuando el catálogo ya tiene quince retos anclados a las Buenas
  Prácticas, con niveles, verbos, competencias y andamiaje declarados.
- Describía dilemas éticos de opción única, que fueron sustituidos por doce dilemas ramificados
  con consecuencia y reparación.
- No mencionaba el gobierno por gates, los registros de decisiones y deuda, ni el núcleo heredado
  de AI StoryLab.
- No declaraba el estado real del contenido, que está validado automáticamente pero pendiente de
  revisión humana línea por línea.

## 3. Qué se conserva de él

El nuevo README hereda del anterior su registro y su carácter: la brújula como imagen, la lista
de lo que la aplicación evita a propósito —rankings, presión por velocidad, competencia tóxica,
acumulación superficial de puntos— y la nota ética de preguntas antes de compartir una
exportación.

Lo que cambió es la exactitud, no la voz.

## 4. Contenido preservado

El texto íntegro del README v0.1A se conserva en el historial de git y en el archivo
`99_ARCHIVO_HISTORICO/versiones_cerradas/2026-08-29_README_EGIA_Quest_v0-1A_INTEGRO.md`.
